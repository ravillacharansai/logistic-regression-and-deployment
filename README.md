# logistic-regression-and-deployment
ents

This repository contains two Machine Learning assignments implemented using Python and Jupyter Notebook. The assignments demonstrate the application of classification techniques and deployment log analysis using data science libraries.

## 📂 Assignments

### 1. Logistic Regression
- Data preprocessing
- Feature selection
- Model training
- Prediction
- Model evaluation using classification metrics

### 2. Deployment Log Analysis
- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Log pattern analysis
- Visualization of deployment logs
- Insights and findings

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/Machine-Learning-Assignments.git
   ```

   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn
   ```

3. Open the notebooks using Jupyter Notebook or JupyterLab.
